Back up & take it with you
Where your journal lives.
Entries are saved in this browser's local storage the moment you type — nothing leaves your machine, and there is no account or server.

That also means it is one copy. Clearing browser data, or opening this file in a different browser, loses it. There is no automatic backup — a browser will not let a local page download files on its own — so the strip at the top of the page turns dark after 7 days or 10 entries until you back up by hand. It counts from when you click, not from a confirmed file, so if you cancel the save dialog it will look done when it isn't.

Markdown export writes a single greppable file with ## 2026-07-31 headers, so your journal outlives this app.
